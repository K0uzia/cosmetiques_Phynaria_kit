# Références — créatures fantastiques et êtres

Fiches documentées (2026-11-04), d'après l'anime et le jeu japonais d'abord, avec la base mythologique ou biologique. À lire avant toute pièce qui évoque l'une de ces créatures, après `.claude/rules/retours-en-jeu.md` et la fiche de style de l'ensemble (`.claude/styles/`). Gabarit commun : codes visuels, proportions du dépôt, matières, mouvement, langage anime, recette dans le mod, pièges, sources.
